==============================================================================
SUPPORTED PREFERENCES
==============================================================================

1. "loudest"       : Select stream with highest RMS energy
2. "quietest"      : Select stream with lowest RMS energy
3. "highest_pitch" : Select stream with highest spectral centroid
4. "lowest_pitch"  : Select stream with lowest spectral centroid

==============================================================================
ALGORITHM DETAILS
==============================================================================

Method: Non-negative Matrix Factorization (NMF) on magnitude spectrogram

Process:
1. Compute STFT of input audio (magnitude + phase)
2. Apply NMF to magnitude spectrogram to estimate components
3. Create soft masks for each component
4. Apply masks to original STFT (preserve phase)
5. Inverse STFT to recover time-domain audio

Advantages:
- Lightweight, no deep learning required
- Fast inference
- Bases already installed (librosa, scikit-learn)

Limitations:
- Modest separation quality
- Works best with 2-3 speakers
- Can produce artifacts with heavy overlap
- No speaker identity preservation

==============================================================================
INTEGRATION WITH HEARING AID SYSTEM
==============================================================================

Workflow:
1. Load multi-speaker audio from dataset
2. Apply sep aration to extract individual speakers
3. Optionally apply hearing aid processing to separated stream

Example:
